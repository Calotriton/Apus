# apus-apus.wav

One call of a common swift (*Apus apus*), played when a run ends.

- **Recording:** Luis Alvarez Menendez, Oviedo, Spain, 3 May 2020, [xeno-canto XC554033](https://xeno-canto.org/554033), through [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Apus_apus_-_Common_Swift_XC554033.mp3).
- **Licence:** [Creative Commons Attribution-ShareAlike 4.0](https://creativecommons.org/licenses/by-sa/4.0/). This file only, not the rest of Apus.
- **Changes:** one call cut out (0.55 s from 1.97 s), band-passed to 3–11 kHz, background noise reduced, faded in and out, resampled to 32 kHz mono. `tools/make_chirp.py` makes it.
